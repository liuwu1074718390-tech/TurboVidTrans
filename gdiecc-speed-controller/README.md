# 21tb 视频极速控制器 (最高 16 倍速防失效)

专门针对 **21tb 网课平台（广东继续教育网等 `*.21tb.com`）** 开发的 Chrome 浏览器扩展。
突破常规插件开启超过 2 倍速即被重置回滚的痛点，最高支持 **16 倍速极速播放**（达到 Chromium 浏览器内核的原生硬件加速极限）。

---

## 核心特性与防失效机制

1. **原型链状态欺骗 (State Spoofing)**：
   - 播放器脚本尝试读取 `video.playbackRate` 时，插件伪装返回 `1.0` 或 `2.0`；
   - 规避网页播放器内部针对 `playbackRate > 2.0` 的防作弊检测逻辑。
2. **防回滚强制锁定 (Rollback Defense)**：
   - 网页播放器尝试将倍速降回 1.0 时，setter 被拦截，底层物理真实倍速仍牢牢锁定在目标值（如 16x）。
3. **事件静默阻断 (Event Suppression)**：
   - 在捕获阶段截断 `ratechange` 事件向页面监听器的传递，阻止播放器触发降速回调。
4. **全 Frame 深度穿透 (Deep Iframe Penetration)**：
   - 自动穿透 21tb.com 的多层嵌套播放器 iframe，自动探测并控制任何动态生成的视频。
5. **防切屏/失焦自动暂停 (Anti-Blur Pause)**：
   - 欺骗 `document.hidden` 和 `visibilityState`，切换标签页或最小化窗口时不暂停视频。
6. **悬浮交互胶囊 + 全局快捷键**：
   - 页面右上方半透明极简控制面板，可折叠、可拖拽；
   - 快捷键支持：`[` 减速、`]` 加速、`\` 恢复原速、`=` 一键 16 倍极速。

## 安装使用指引（只需 1 分钟）

### 步骤 1：打开 Chrome 扩展程序管理页
在 Chrome 浏览器地址栏中输入并回车：
```text
chrome://extensions/
```

### 步骤 2：开启“开发者模式”
在扩展程序页面**右上角**，找到并打开 **“开发者模式” (Developer mode)** 开关。

### 步骤 3：加载已解压的扩展程序
1. 点击左上角的 **“加载已解压的扩展程序” (Load unpacked)** 按钮；
2. 在弹出的文件选择器中，选中当前插件文件夹：
   ```text
   /Users/liuwu/Desktop/造价数据平台/tools/gdiecc-speed-controller
   ```
3. 点击“选择”完成安装。

### 步骤 4：固定并使用
1. 在 Chrome 工具栏右上角的拼图图标（扩展程序）中，找到 **“21tb视频极速控制器”** 并点击图钉固定；
2. 刷新目标网课页面（如：`https://gdiecc.21tb.com/...`）；
3. 页面右上角将出现悬浮调速条，或直接点击浏览器右上角插件图标，自由切换 **1x ~ 16x** 倍速！

## 快捷键一览

| 按键 | 功能说明 |
| :---: | :--- |
| `[` | 播放速度 **-0.5x**（最低 0.1x） |
| `]` | 播放速度 **+0.5x**（最高 16.0x） |
| `\` | 恢复正常速度 **1.0x** |
| `=` / `+` | 一键飙到 **16.0x 极限速度** |

> 注：在页面的输入框（input、textarea）内打字时会自动禁用快捷键，防止打字误触。

## 文件结构说明

- `manifest.json`：扩展清单（Chrome MV3 规范，配置 MAIN 与 ISOLATED 双世界注入）。
- `inject.js`：运行于宿主页面主执行环境（MAIN World），负责 `HTMLMediaElement` 原型劫持与事件拦截。
- `content.js`：运行于内容脚本环境，负责页面悬浮 UI 渲染、拖拽定位与快捷键监听。
- `ui.css`：悬浮面板的现代化毛玻璃拟态样式。
- `popup.html` / `popup.js` / `popup.css`：浏览器工具栏弹出面板。
- `icon16.png` / `icon48.png` / `icon128.png`：插件图标。
